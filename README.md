# Basic RAG App

A full-stack RAG chat/workspace application built with React and FastAPI.

## Tech Stack

| Folder | Description| Tech |  
|--------|---------|---------|
| `backend/` | Backend | FastAPI, PostgreSQL, PGVector, SQLAlchemy, Redis, JWT, Sentence Transfomers, OpenAI  |
| `frontend/` | Frontend | React, TypeScript, RadixUI |
