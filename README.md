# Basic RAG App

A full-stack RAG chat/workspace application built with React and FastAPI.

## Tech Stack

| Folder | Description| Tech |  
|--------|---------|---------|
| `backend/` | Backend | FastAPI, PostgreSQL, PGVector, SQLAlchemy, Redis, JWT, Sentence Transformers, OpenAI  |
| `frontend/` | Frontend | React, TypeScript, RadixUI |


## Features

- Data Validation
- Chunking
- Embedding (Sentence Transformers)
- Ingestion
- Hybrid Retrieval (Vector and Keyword search)
- Reranking
- Prompt Building
- Answer Generation
