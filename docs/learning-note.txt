# RAG Learning Notes

## What is RAG?

It stands for Retrieval Augmentation Generation that is technique to provide external knowledge base by using external data sources (companies private data sources mostly used .md, .pdf files) to LLMs (Large Language Models). It is the most critical pillar of Generative AI Layer.

Basically it breaks down into three components:-

- Retrieval =  Find useful information
- Augmentation = Add it to AIs (LLM) knowledge
- Generation = Generate Response

It makes LLM answers more reliable by searching most relevant information and generating response about that topic.


## What is an embedding?

Embedding is a process, that converts the user input chunks whether its text, images, videos, document files etc. into numerical vector values that capture semantic meaning, which are then stored in a vector database for fast similarity searching.
